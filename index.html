DATA EXPLORATION · SORTING ALGORITHMS

암 발생자 수 정렬 탐구

2023년 암종별·성별 암 발생 현황 데이터로 비교하는 두 가지 정렬 알고리즘

탐구 목표
같은 50개 암 발생 건수를 버블 정렬과 선택 정렬로 내림차순 정렬하며, 각 단계의 비교와 교환 과정을 나란히 관찰합니다.
50개 데이터가 미리 입력되어 있습니다. 별도로 숫자를 입력할 필요가 없습니다.
ALGORITHM 01

버블 정렬

이웃한 두 값을 비교하고, 순서가 맞지 않으면 서로 교환합니다.

비교 횟수0
교환 횟수0
진행 단계0 / 0
정렬을 시작하면 각 단계가 여기에 표시됩니다.
ALGORITHM 02

선택 정렬

정렬되지 않은 부분에서 가장 큰 값(또는 작은 값)을 찾아 앞에 배치합니다.

비교 횟수0
교환 횟수0
진행 단계0 / 0
정렬을 시작하면 각 단계가 여기에 표시됩니다.

색상 안내: 주황색은 현재 비교 중인 값, 초록색은 정렬이 완료된 위치, 파란색은 아직 정렬 중인 값을 나타냅니다.
※ 그래프에는 입력 자료의 50개 발생 건수를 순서대로 표시했습니다. 이 페이지는 정렬 알고리즘의 작동 과정을 살펴보기 위한 탐구용 시각화이며, 각 막대 번호는 원자료의 순서를 뜻합니다.
